# Diseños Draguz Shop

- `listos-para-imprimir/`: PNG sin fondo para DTF (300 dpi).
  - `*-playera-negra.png` / `*-sin-negro.png`: solo se quitó el negro puro, para playera negra (menos plasta).
  - `*-contorno.png` / `*-sin-fondo-letras.png`: diseño sólido con contorno, para playeras de color.
  - `*-sin-blanco.png`: se quitó todo el blanco.
- `mockups/`: mockups. Los `*-tormenta.jpg` son el estilo de la marca (nubes y rayos del color del diseño). `generador-tormenta.py` los genera.
